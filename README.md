# CODSOFT Internship Projects

This repository contains the three projects completed as part of my CODSOFT internship, showcasing my experience applying programming concepts to practical tasks and building functional applications.

**Tasks**

**Task 1 - Number Guessing Game:** 
A console game where the users guess a randomly generated number with "too low" or "too high" as feedback.

**Task 2 - Simple Calculator:**
A basic calculator supporting addition, subtraction, multiplication, and division.

**Task 3 - To-Do List:**
A console-based task manager that allows users to add, view, delete, and mark tasks as completed.

**Technologies Used**

C++
Standard C++ libraries

**Internship**

During the internship, I completed three assigned development tasks, gaining hands-on experience with problem-solving, programming, debugging, and building functional projects.
